# Sayfern wireframes

Design source for the Sayfern UI (10 screens, Stages 1-3).

- Live, clickable canvas: https://claude.ai/code/artifact/df6065c0-d9d0-4814-8049-067b5608131e
- `*.dc.html` are the artboard sources (Design Component format). They render inside the canvas above, not standalone in a browser.
- `canvas.json` is the board layout.

| File | Screen | Stage |
|---|---|---|
| Welcome.dc.html | Welcome + provider setup | 1 |
| Today.dc.html | Sessions home | 1 |
| Main.dc.html | Chat session | 1 |
| Reader.dc.html | Library reader (Japanese) | 1 |
| Grammar.dc.html | Grammar page | 1 |
| Progress.dc.html | Local stats | 1 |
| Corrections.dc.html | Corrections + Anki export | 2 |
| Quiz.dc.html | Quiz builder | 2 |
| Customize.dc.html | Feature builder | 2 |
| Voice.dc.html | Voice session | 3 |
